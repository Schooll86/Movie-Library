# Movie-Library

## Автор
Коломиец Милана

## Описание
Приложение для хранения информации о фильмах с возможностью фильтрации и сохранения данных в JSON.

## Функции
- Добавление фильмов (название, жанр, год, рейтинг)
- Просмотр списка фильмов
- Фильтрация по жанру
- Фильтрация по рейтингу или году
- Сохранение данных в JSON
- Загрузка данных из JSON

## Требования
- Python 3.x

## Запуск
1. Установить Python
2. Открыть проект
3. Запустить:

   python main.py

## Пример JSON
{
  "title": "Inception",
  "genre": "Sci-Fi",
  "year": 2010,
  "rating": 8.8
}
